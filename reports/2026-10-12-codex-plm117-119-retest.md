## Bug 117：在线批注无法新增，批注列表与当前文件脱节

- 页面：研发 → 图文档与 CAD → 在线预览与批注
- 路径：`/plm/document-cad/preview-annotation`
- 操作：
  1. 打开页面并等待文件列表加载。
  2. 选择 `ERP-FG-001_gearbox_assembly.dwg`。
  3. 查看右侧批注并点击“新增批注”。
- 实际结果：
  - 右侧仍显示“第 2 页 / 右上角”“模型视图 / 剖面 B”“标题栏”三条固定批注，内容、责任人和日期没有随当前文件变化。
  - 点击“新增批注”后没有弹窗、表单、提示、路由变化或其他创建流程。
- 结论：沿用 Bug 117，待修复。

## Bug 118：版本对比和导出结果使用旧目标版本

- 页面：研发 → 图文档与 CAD → 图纸版本对比
- 路径：`/plm/document-cad/drawing-compare`
- 操作：
  1. 打开页面，默认版本为 `DRW-AXLE-001 / A.1` 与 `DRW-AXLE-001 / B.1`。
  2. 基准版本切换为 `DRW-AXLE-001 / A.2`。
  3. 目标版本切换为 `DRW-AXLE-001 / B.2`。
  4. 点击“生成差异”，再点击“导出报告”。
- 实际结果：
  - 页面标题和两侧版本视图显示 `A.2`、`B.2`。
  - 差异表首行仍为 `A.2 -> B.1`，其余材料、零部件和批注差异也没有重新计算。
  - 页面只提示“已按当前双版本生成差异清单”。
  - 导出文件名为 `drawing-compare-A.2-to-B.2.txt`，但文件正文仍写成 `A.2 -> B.1`。
- 证据：[错误的 B.2 对比导出](../evidence/2026-10-12-codex-plm117-119-retest/drawing-compare-A.2-to-B.2.txt)
- 结论：沿用 Bug 118，待修复。
