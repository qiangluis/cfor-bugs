## Bug 112：文档模板新增假成功，整页刷新后丢失

页面：研发 → 图文档与 CAD → 文档模板  
地址：`/plm/document-cad/document-template`

### 复测步骤

1. 点击“新增模板”。
2. 填写模板编码 `TPL-CODEX-20261012`、模板名称 `Codex 测试模板`。
3. 选择编号规则 `DOC-{产品编号}-{阶段}-{流水号}`。
4. 选择审批规则 `文控审核 + 质量会签`。
5. 选择影响范围“文档库”，点击“确定”。

### 实际结果

- 页面提示“文档模板已新增”。
- 模板表格仍只有原有 3 条：`TPL-DOC-SPEC`、`TPL-DRW-2D`、`TPL-CAD-DWG`，没有新增行。
- 右侧明细卡片在当前页面短暂显示“Codex 测试模板”，说明页面内存状态被修改。
- 点击页面“刷新”后，右侧明细回到固定首条模板。
- 浏览器整页重新加载后，新模板完全消失，表格仍为原有 3 条。

### 源码与修复边界

`cfor-admin-vue3/src/views/plm/document-cad/document-template/index.vue` 当前使用普通数组 `templateRows`；保存逻辑只是把新对象插入前端数组并弹出成功提示，没有正式 API 调用。  
后续修复需要补齐服务端事实源、列表/新增/编辑/详情持久化、租户和权限校验，并让新租户初始化与存量租户补缺只补不存在的模板，不覆盖已有配置。编号规则、审批规则不能继续只保存中文演示字符串。

## Bug 113：已有标签维护表单全部为空

页面：研发 → 图文档与 CAD → 分类 / 标签  
地址：`/plm/document-cad/category-tag`

### 复测步骤

1. 打开已有标签 `TAG-RELEASE / 发布必选`。
2. 点击该行“维护”。

### 实际结果

“维护标签”弹窗能够打开，但以下字段全部为空或显示未选择：

- 标签编码
- 标签名称
- 适用对象
- 权限范围
- 引用页面

该标签在列表中已有完整值：适用对象为“文档版本 / 图纸版本”，权限范围为“文控可维护，研发可查看”，引用页面为“文档基线、发布包”。因此不是该标签在列表中没有数据，而是行数据没有正确传入维护表单。

### 源码与修复边界

`cfor-admin-vue3/src/views/plm/document-cad/category-tag/index.vue` 的操作列插槽没有解构 `row`，但按钮调用了 `openTagDialog(row)`；同时保存仍操作固定前端数组，没有正式 API 持久化。  
修复必须同时覆盖：已有标签回显、编辑更新而不是无条件新增、服务端租户隔离与权限、新租户初始化、存量租户补缺，以及刷新/重新登录后的持久化回查。不能只补 `#default="{ row }"` 后就把编辑闭环标记为通过。
