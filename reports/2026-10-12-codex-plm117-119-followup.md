## Bug 117：在线批注无法新增，批注列表使用固定演示数据

- **路径 / 级别**：研发 → 图文档与 CAD → 在线预览与批注，`/plm/document-cad/preview-annotation`，P1。
- **复现步骤**：
  1. 打开在线预览与批注页面，页面能够加载文件树和 9 条生产文档。
  2. 选择 `ERP-FG-001_gearbox_assembly.dwg`。
  3. 查看右侧批注列表并点击“新增批注”。
- **实际结果**：
  - 右侧仍显示固定的三条批注：`第 2 页 / 右上角`、`模型视图 / 剖面 B`、`标题栏`，内容、责任人和日期不随当前文档切换。
  - “新增批注”没有弹出表单、没有提示、没有路由变化，也没有进入任何创建流程。
  - 在 1280px 视口中，按钮 DOM 的边界为 `x=1280, width=109`，整个按钮从视口右边开始，视觉上不可见；页面标题区实际只看得到“刷新”。
- **源码依据**：
  - `cfor-admin-vue3/src/views/plm/document-cad/preview-annotation/index.vue` 将 `annotationRows` 定义为固定数组。
  - “新增批注”按钮没有 `@click` 或弹窗状态绑定。
- **预期 / 修复要求**：
  - 批注应以文档 ID、当前修订 ID 为事实源，切换文档时只展示该文档批注。
  - 新增批注需要有权限校验、定位信息、正文、责任人、状态、审计字段和服务端持久化；成功后刷新/重新登录仍能回查。
  - 页面布局应保证按钮在默认视口可见，不能用固定演示数组或只补前端提示代替正式链路。

## Bug 118：图纸版本对比切换版本后差异表不重新计算

- **路径 / 级别**：研发 → 图文档与 CAD → 图纸版本对比，`/plm/document-cad/drawing-compare`，P1。
- **复现步骤**：
  1. 打开页面，初始基准版本为 `DRW-AXLE-001 / A.2`，目标版本为 `DRW-AXLE-001 / B.1`。
  2. 展开基准版本下拉，切换为 `DRW-AXLE-001 / A.1`。
  3. 点击“生成差异”。
- **实际结果**：
  - 页面标题和基准版本视图更新为 `A.1`。
  - 差异表仍显示旧固定数据，首行仍为 `A.2 -> B.1`，其他材料、零部件和批注差异也全部不变。
  - 点击“生成差异”只出现“已按当前双版本生成差异清单”提示，没有新的查询或计算结果。
- **源码依据**：
  - `cfor-admin-vue3/src/views/plm/document-cad/drawing-compare/index.vue` 使用固定 `diffRows` 数组。
  - `generateDiff()` 只有成功提示，没有调用 API，也没有根据两个选择器重建差异。
  - 版本候选项也是页面内固定字符串，不是当前租户的正式图纸版本数据。
- **预期 / 修复要求**：
  - 版本候选项应来自正式图纸/修订 API，并限制为同一图纸的可比版本。
  - 生成差异必须以当前基准版本 ID、目标版本 ID 查询或计算，差异表、两侧预览和影响说明必须保持同一对版本。
  - 导出报告只能导出当前计算结果，不能导出固定演示数据。

## Bug 119：图纸版本对比导出按钮在默认视口被裁切

- **路径 / 级别**：同 Bug 118，`/plm/document-cad/drawing-compare`，P2。
- **实际结果**：
  - 在当前 1280px 浏览器视口中，“导出报告”按钮边界为 `x=1191.82, right=1309`，右边超出视口 29px，截图中按钮文案被右侧裁切。
  - “生成差异”和“导出报告”的 DOM accessible name 均包含多余的前导 `>` 字符，例如 `>导出报告`；该字符来自模板中 `><Icon ...` 的多余文本，影响无障碍名称和自动化定位。
- **预期 / 修复要求**：
  - 页面应在默认桌面视口内完整展示标题、版本选择器和所有操作按钮；必要时采用可收缩操作区或响应式布局，而不是把操作推出视口。
  - 清理按钮模板中的多余字符，并补充默认 1280×720 视口的布局回归。
